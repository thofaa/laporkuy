# Laporkuy

Web app untuk pelaporan (masih tahap awal, bentuk akhir belum fiks).

## Cara Jalanin

1. Install [Bun](https://bun.sh), lalu:
   ```bash
   bun install
   ```
2. (Opsional) Siapkan env:
   ```bash
   cp .env.example .env
   ```
3. Jalankan:
   ```bash
   bun dev
   ```
4. Buka http://localhost:3000
